# P3 结构化笔记与历史：执行契约 v1

状态：P3开始，未验收。依据[ADR 0032](adr/0032-structured-memory-notes-and-history.md)；P2封存见[阶段报告](results/memory-v2-p2-2026-11-11.md)。本契约不改变P2判据或旧成绩。

预算：每个domain/adapter/故障case外层30秒；Loop使用12步、16工具、8000 Token、30秒，边界case只缩小对应额度。合成operator/证据不代表用户批准；真实模型调用0。私有Store/Evidence在Actor工作区外，真实SQLite和目录描述符/原子发布用于允许路径；拒绝路径可以注入禁止I/O探针。

| case_id | 固定触发 | 必须证明的行为 |
| --- | --- | --- |
| N01 | 同字段笔记、乱序JSON、普通旧文本 | 规范序列化稳定，往返字段不丢；旧文本/旧批准hash原样；未知版本/字段/重复键拒绝 |
| N02 | 空字段、bool修订、重复来源、supersedes不在sources、>2KiB、Secret | 边界严格拒绝；不裁掉来源/例外，不把验证说明当事实 |
| N03 | 改trigger/rule/verification/exception/source或替代关系后再用旧批准 | 任何变更使hash改变；修订清除旧证据与批准，旧提交不可重放 |
| N04 | 合并引用两个旧证据；给新笔记传旧hash/旧run | 旧证据不能验证新主张；新的专属run/证据经现有类型/范围/独立验收要求才可validated |
| N05 | version1有proposed/validated/approved/committed/rejected条目；显式迁移 | 现有条目/批准bytes与备份一致；仅当前快照历史，不伪造旧过程；重复迁移无改动；普通读取无迁移 |
| N06 | 未知版本、损坏库、路径/符号链接/硬链接、备份冲突、迁移中取消/故障 | 拒绝且原库不变；允许保留hash正确的审计备份，无半迁移库；已启动线程收束后释放维护守卫 |
| N07 | 一条笔记创建→验证→批准→提交→修订→拒绝；历史分页 | 所有真实状态在历史中按序可读；当前状态与追加历史原子；跨项目隔离；历史不能改或删除 |
| N08 | 人工合并、在运行内调用维护、无权限调用、旧适配器 | 合并只产生proposed；来源修订/指纹/证据真实复查；维护不进入模型注册；拒绝在I/O前；不支持历史则安全拒绝 |
| N09 | 两条旧条目→新已批准替代；commit前修改任一旧引用或注入发布故障 | 正常时一次事务提交新条目并supersede全部旧条目；异常时全部不变；旧批准/过期引用不可重放 |
| N10 | 同ID自身替代、关系环、跨项目/版本来源、冲突topic | 全部拒绝；不能借替代绕过冲突或项目隔离；未提交新提议不撤销旧知识 |
| N11 | 100当前条目、历史累积至8MiB、超过分页上限 | 限额拒绝，不自动淘汰；失败后当前状态/历史/文件集符合发布契约；完整包裹预算仍有界 |
| N12 | local/configured/Conversation、v1/P2旧库、新结构化笔记、两个示例 | 新旧读取/批准兼容，条件/撤回/权限/统一计账保持；CLI明确迁移/审阅/合并/替代并输出真实来源；四门禁和真实OS回归通过 |

预期产物：新增domain笔记/来源契约；最小历史端口；SQLite显式迁移、历史和批量替代事务；运行外维护工具/CLI；结构化proposed工具和两条组装；离线例子；逐行证据矩阵与阶段报告。当前未实现部分仍保持not_run，不因domain测试通过就签整行。

执行澄清（验收前固定）：N06的“取消/失败原库不变”适用于最后发布检查点之前；越过该检查点后，取消/通知失败必须读回确认已提交版本，不能声称回滚。N12运行三个离线示例（v1、P2、P3），所有原有Memory契约与四项迁移后OS探针均重新运行，不复用P2结果。
