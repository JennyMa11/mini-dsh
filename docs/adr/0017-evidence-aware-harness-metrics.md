# ADR 0017：指标区分观测、独立判据和未测状态

- 状态：Accepted
- 日期：2026-10-03

## 背景

轻量公开修复题 12/12 通过验证了任务可用性，却无法说明上下文压缩、恢复和安全机制
是否有效。用户提供《Agent 评估指标体系》，要求吸收其中适用指标。现有 Trace 足以
生成部分路径指标，但“选得对”“确实恢复”“正确拦截”需要独立预期和实际副作用证据。

## 决策

增加独立的只读 `evaluation.harness_metrics` 和 `trace metrics` 入口，核心 Loop、工具
协议和旧报告 schema 保持兼容。分开报告 Component、Trajectory 和 End-to-End 证据，
不将其合成一个可由成功率抵消安全失败的总分。

Trace 直接生成调用错误、相邻失败重复、Token、缓存和耗时指标。任务成功、工具选择、
恢复事件、安全探针和人工接受需要独立 sidecar，绑定 `run_id` 并记录判据来源。
每个比例记录分子、分母、声明机会和检查覆盖率，分母为零时返回 `null`。
聚合合计分子分母，不能平均比例。预算检查只用显式声明的限额；超出名义 Token 限额
与最终修复通过分别报告，未知用量不能判为零或预算通过。

旧基线只做派生统计，另存输入/评分器 hash 和复现脚本，保持冻结实验和原始 Trace。
用户要求只统计 Token，新增视图不计算货币费用；既有历史报告仍保留原始记录。

## 替代方案

- 全部由 LLM judge 打分：增加用量和偏差，安全和预算仍需要可执行判据，暂不采用。
- 把 denied 次数当安全拦截率、把后续成功当恢复：缺少正确分母和因果，拒绝。
- 给未触发项记 100%：制造无法支持的功能结论，拒绝。
- 重写全部 Benchmark schema：会破坏历史比较；先提供可再生成的独立视图。

## 后果与迁移路径

已有 Trace 无需再次调用模型即可增强报告。语义检查依赖 sidecar 的真实判据，来源
字段不能替代审核；无标签的历史实验保持未测。当前重复动作只提供保守代理，恢复
需要专项注入和检查点。未来 runner 可写出同一契约的 sidecar，将其接入报告，随后
扩展 case manifest 的预期/禁止行为；保留旧 Trace 与评分版本，避免追溯污染。
