# ADR 0047：整账期覆盖预审与保留全部前序消费的财务结转

- 日期：2026-11-07
- 状态：Accepted（只读审计；证据通过后才可结转）

## 范围

先刷新JennyMa账单、核对产品/时区/工作空间和全部原始请求覆盖，评估能否以完整
工作空间已结算金额上界替换重复或过高估价。只读取自有历史SDK资源，不创建会话、
采样或训练，不支付、充值、使用重置卡或删除权重；不改变50元上限和旧科学结论。

若全范围证据充分，使用新accounting epoch，不覆写原calibrated-budget或历史账本。
新carryover保留前序全部operation ID，父文件/hash、账单ID和已覆盖金额必须可追溯，
防止重复抵扣。现有CalibratedBudget可读取新audit/carryover，无需改核心或计费代码。
保留所有当前未覆盖非采样估价及2元不确定预留，不把metadata API推定为免费。

## 门禁与替代

只有范围、归属、闭合账期、操作分母、金额和独立复核均一致才发布新epoch。
账单显示是工作空间上界，不是项目逐请求精确实付。存储账期单独说明；未闭合或
不明范围继续留预留。输入变化、未知RPC、账单遗漏/重叠或金额不一致即拒绝。

若不能证明覆盖，只保存候选与缺口，活动账本保持不变。资金容量不代表学习机制
通过，也不构成启动新实验的授权；准备/inspect与实际run继续分开。
