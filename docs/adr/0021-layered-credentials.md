# ADR 0021：全局与工作区分层密钥配置

- 状态：Accepted with limitations
- 日期：2026-10-03

## 背景

个人终端使用需要跨进程复用 API Key，并允许不同工作区选择自己的 Key。
原 `/key` 仅在进程内存保留，用户明确要求保存到项目目录。此要求取代 ADR 0019
中终端密钥不持久化的决策；GUI 临时设置仍保持内存行为。

## 决策

密钥配置与模型可见的运行选项分开：全局文件默认位于
`~/.config/minidsh/credentials.toml`，可用 `MINIDSH_CONFIG_HOME` 指定绝对目录；
工作区文件位于 `.minidsh/credentials.toml`。`[credentials]` 按 provider 的 API Key
环境变量名存储字符串，不将密钥放进 `RuntimeOptions`、模型 Prompt 或配置展示。
按环境变量 > 工作区 > 全局逐 Key 解析，空值不遮蔽低优先级有效值。
工作区继承全局时不复制文件或 Key。畸形配置报告安全错误，不回显原始数据。

交互模式启动显示来源，在首次需要模型时发现缺少凭据则隐藏输入；配置后继续
原任务，不要求用户再次输入任务。用户也可主动 `/key` 更新当前 workspace Key。
本地查看与固定测试无需模型凭据，不触发 Key 输入。取消或隐藏输入不可用时回到
提示符；适配器配置失败不落盘。持久化失败明确显示仅当前会话可用。
手动输入优先于当前会话环境值；重启后恢复声明的分层优先级。

保存是可信 CLI 发起的独立 Tool Runtime 操作，授予专用 `credentials.write` 能力。
密钥绑定在内部工具实例，不进入 ToolCall 参数、Observation 或 Trace。
该工具不注册到模型的工具表，模型不能调用它或自行授予保存权限。
配置目录创建、Git 忽略与密钥替换均在该工具执行内完成；采用原子替换，密钥文件
由 `mkstemp` 创建为 `0600`。保存前检查工作区路径与符号链接，保留其他 provider
配置及原有 `.gitignore` 条目。忽略规则不移除已跟踪的 Git 文件。

`credentials.toml` 纳入敏感文件规则，文件读取、写入与 Patch 不允许模型访问它。
Context 检索复用同一路径与敏感文件检查，防止可见别名指向密钥配置。
接入模型时使用进程内环境映射，不修改 `os.environ`；已知 Key 的脱敏 wrapper
用于 provider 输出、工具参数与错误，已有 Trace 脱敏继续生效。

## 替代方案

- 继续只使用环境变量或内存：不能满足项目持久化与覆盖需求。
- 把 Key 放在项目根 `minidsh.toml`：该文件可能进入仓库和模型 Context，选择独立敏感文件。
- 将密钥作为通用写文件工具参数：可能进入调用事件，选择绑定值的内部工具。
- 将输入默认保存到全局：用户要求保存到项目，避免影响其他工作区。

## 验收与边界

离线检查环境/工作区/全局优先级、其他 provider 与空值回退、畸形文件安全错误、
持久化权限、Git 忽略、原有 Key 保留、符号链接拒绝、工具与检索访问阻止、首次
任务配置后执行和重启复用、保存失败反馈，以及 Session/Trace/回答不出现已知 Key。
测试使用临时目录和脚本 provider，不访问真实密钥或模型服务。

这是用户授权的本地明文存储，不是 OS Keychain 或加密密钥库。程序白名单授权的
本地 Shell/解释器不是操作系统级隔离；本次不宣称阻止所有已授权外部程序读取
凭据。既有本地文件检查的并发替换限制继续适用。配置文件不会自动修改全局默认
Key，GUI 页面输入不新增持久化行为，历史评测报告与冻结配置不改写。
