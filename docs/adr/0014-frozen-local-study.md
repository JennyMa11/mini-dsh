# ADR 0014：冻结本地小模型实验协议

状态：接受（2026-09-29）

## 背景

先前的 2 任务 pilot 显示 8B 在优化 Harness 下 Token 与耗时下降，但样本小，无法支持总体成功率结论。七阶段消融也不利于识别主要机制。项目需要可审计、可恢复的正式本地实验，而非继续堆 Agent 功能。

## 决策

冻结 26 个自建任务、完整输入/验证/参考解哈希、Qwen3 4B/8B MLX Q4 快照与固定预算；每格 greedy 重复 3 次。矩阵采用 Baseline 与 Optimized，8B 消融缩为五个累积阶段。留出判据在 Agent 运行后覆盖，离线门禁先验证原始任务失败与参考解通过。每次运行立即写 checkpoint 和 Trace；协议哈希不符时拒绝恢复。统计以任务聚类，并保留逐次原始数据。

## 权衡与替代方案

没有直接使用 SWE-bench：本机单机预算与验证环境难以先保证可复现。自建任务更易固定，但外部效度有限，报告必须写明。没有把三次 greedy 重复当成独立样本；它们只刻画同一任务的运行稳定性。没有把 macOS 全机内存空闲率当作模型占用；进程 `phys_footprint` 与 MLX allocation peak 分别记录。最后一层消融捆绑 Loop Guard 与恢复，不能声称二者各自的因果贡献。

## 迁移

旧 `matrix` 与七阶段 `local_first` suite 保留给 pilot 复现。新实验使用 `formal-study` 和 `local_formal/v1`，不得把两套报告直接合并。若任务、判据或 Harness 代码更改，递增协议版本并重跑完整矩阵。
