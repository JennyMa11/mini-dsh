# ADR 0048：固定完整队列，按确认阶段检查可用资金

日期：2026-11-07；状态：Accepted（离线实现，未运行真实实验）。

旧账本证据不足以释放全部预留，而一次性预留整轮最坏费用阻止获得Readiness证据。
为保持50元上限且不改80条科学队列，新plan可显式选择confirmed_stage_v1：完整
Readiness、单个完整训练组、完整test分别准入；不足时只在已确认边界等待结算。
原full_remaining_v1仍是默认，旧计划及其归档不改。此决策仅调整实验控制面资源策略，
不改变核心Agent Loop、算法、任务、seed、成功门槛或测试分母。

原20.302元整轮分配仍约束累计新增占用及全部剩余动作；共享额外额度仍0.50元。
阶段模式最多12次恢复，覆盖10个阶段及有限故障恢复，恢复每次0.01元从共享额度扣除。
资金等待不创建SDK会话、不消耗恢复次数；再次执行若没有占用下降，直接保持等待。
占用下降不是账单覆盖证明，实际reconcile仍需独立闭合账期/请求归属审计；本控制器
不自动释放费用或修改历史账本。未知RPC、pending、初始权重或来源变化继续拒绝。

替代方案是提高上限、缩小科学队列或未经证明释放旧费，均不采用。代价是研究可能
因结算延迟分段，甚至无法完成；未运行项保留，部分结果不支持完整RL收益结论。
模式必须绑定plan及execution-config，修改实现后重新prepare，不临时更改旧冻结文件。
本阶段先契约/故障验收、后实现，仅离线prepare/inspect；用户此前停止真实实验的
指令继续有效，资金容量本身不授权模型或训练请求。
