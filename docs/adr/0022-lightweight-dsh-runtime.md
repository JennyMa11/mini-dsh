# ADR 0022：轻量 DSH 的交互与运行时闭环

- 状态：Accepted
- 参照：deepseek-ai/deepseek-harness，提交 d743267388641bc76f17c45ce8b4c231aed1d32c

采用 Python 独立实现，保留 complete、旧 run 日志与显式组装 API。
可选流式接口只发布脱敏文本，完整响应结算后才执行工具；取消不回滚文件，
未知用量独立记录。交互审批只收紧启动权限，拒绝规则不能通过审批覆盖。

新增受控请求/工具钩子，改写后重新校验和授权；观察事件不作为策略拦截器。
通过稳定 ID 组合内置和已安装 Python 插件，外部插件须显式信任；不自动安装，
不兼容 Cordis/npm。插件代码为可信宿主代码，不是沙箱内的不可信代码。

稳定 Session 在存储 adapter 中跨轮追加，单写者锁由平台 adapter 实现。
分叉仅复制已结束轮次的消息事实，不回滚工作区。旧记录保留，导入记录来源。
文件和进程工具共用显式后端；Context 检索只使用受控快照。

终端优先，GUI 共用审批及增量事件协议；保留 loopback 认证与有界展示。
真实模型验收固定六类场景、两次重复、总名义预算 120000 Token；失败、取消、
未知和未运行均保留，测试与机制收益分开报告。

替代方案：直接嵌入 Node DSH 会改变运行时与插件信任范围；全局自动插件发现会
使仓库配置变成代码执行；取消时撤销修改会覆盖用户文件，因此均不采用。

迁移：新增能力使用可选端口和兼容 adapter；旧 Benchmark 保持非流式配置，
旧实验产物不覆盖。每阶段通过契约、安全、集成与全量质量门禁。
