# ADR 0037：先验证交互可学习性，再比较 RL 算法

- 日期：2026-11-07
- 状态：Accepted（开发阶段；模型收益仍待实测）
- 授权：用户目标“先解决交互可学习性，再继续比较 RL 算法”。

## 决策与当前范围

沿用ADR0034/0036的独立实验包。当前只接入已评审的工具示例开关，完成控制流、
本地tokenizer与任务检查，准备原Prompt/追加示例的32条同期配对开发评测。
两组均为interactive；任务、工具、模型、采样、判据和全部资源额度不变。
原Prompt保持字节一致，示例仅追加一次。该对照估计增加整段示例的效果，不能
独立归因于语言、示例语义或额外上下文长度。

确定性脚本及合成Token只能用于Component/Trajectory验收；必须显式标记，
不得上传成模型训练曲线、用于训练或宣称真实模型已学会反馈修复。
模型评测须保留完整队列、原始采样、policy/variant绑定和独立验证。

## 替代方案与退出

暂缓同时增加步数、修改任务难度、批量读取工具或换模型，以保留单变量解释。
示例若无效，基于完整失败数据另定下一项开发假设；不降低预声明门槛或补采样凑收益。
停用`--prompt-study`即可保留原工作流；旧轨迹及源码归档不覆写。
