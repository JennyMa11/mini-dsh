# ADR 0051：开发反馈v3，仅重新验收可学习性

- 日期：2026-11-08
- 状态：Accepted（用户明确继续修订数据、冻结新版本、重新开发准入）

## 范围与选择

沿用ADR0050的独立实验包。本次只有6道已打开开发题，重新采样一次24条G4；
不构建新训练/验证集、不启动训练、不比较算法。v1/v2评分和原始轨迹保留。

v2两路由组全失败、表连接一组全成功一组全失败。原公开测试首个断言/异常就停止，
路由被同一exact-method提示遮蔽最长前缀，表连接被mode异常遮蔽顺序和值合同。
这支持先检查反馈的可行动性，尚不足以把失败唯一归因于反馈，也不靠改任务阈值凑信号。

新curve_development_v3保留这6题的spec、业务源码、双缺陷组合、reference、私有
检查逐字节不变，仅更新public_tests.py；构造逐合同独立输入，报告期望/实际/异常，
一次测试完成全部检查，最后统一失败。新增输入和报告格式是一个组合修订，不宣称
仅格式的单变量因果收益。原两道依赖题保留作开发参照，不按新模型结果再筛题。

## 验收与执行

私有仍curve_private_v2，公开版本curve_public_feedback_v3；新ID显式隔离。
6题×7预设候选×公开/私有=84项完整真实容器复验。只覆盖当前开发数据，不把未触发
的训练/验证或全规格正确性补认为通过。

保持Qwen3.5-4B、原初始零LoRA权重、tool_example、batch_read_eight、预算和采样参数。
保留v2同题repeat的seed，控制开发采样设置；没有同期旧版对照，结果仅作探索性准入。
阈值不变：6组完整、>=3混合组覆盖>=2算法组，成功6–18/24，真实失败反馈后修复
覆盖>=2算法组。通过也只交付准入，不自动训练。

复用v2唯一活动financial epoch，累计150/新增100档不变；本轮额外硬上限3元，完整
采样与连接上界2.22元。不迁移或另建财务账本，不改历史预留。只连接已有sampler，
无trainer/optimizer接口、无新checkpoint。原始Token/logprob与财务绑定继续封存。

## 实施结果

84项数据检查通过；24条实际开发成功8次，4/6混合组覆盖2算法组，反馈后修复3条
覆盖2算法组，原阈值全部通过。业务源码、缺陷、私有检查保持旧版本，历史分数不改。
只连接已有零LoRA sampler；无新trainer、checkpoint或更新。额外保守占用1.515元，
累计52.104元，无pending。阶段结束，不自动训练，效果边界见执行记录。
