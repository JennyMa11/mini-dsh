# ADR 0052：通过 v3 准入后冻结单 seed 学习曲线 v4

- 日期：2026-11-09
- 状态：Accepted（用户要求继续下一阶段）

## 范围与选择

继续 ADR0050 的独立 RL 实验包，不向核心 Runtime 添加训练依赖。
v3 开发准入已通过；复核其封存源码、24 条原始轨迹和反馈证据后复用，
不重新采样开发题。新 curve_dataset_v4 只含原来未打开的 12 train、12 validation，
排除所有 index 4/5 开发实例。业务源码、规格、双缺陷、参考解及 curve_private_v2
逐字节不变；公开测试统一采用 v3 的逐合同期望/实际/异常反馈。
这不是新增算法家族或开放最终测试集。

## 冻结与门禁

24 题 × 7 预设候选 × 公开/私有 = 336 项容器检查，正确实现必须通过，
预设缺陷必须被指定检查识别。完整检查通过且财务、安全、数值协议有效，才运行模型。
从 v3 所用原始 optimizer 恢复，保存新 sampler 后下载真实 adapter，逐 tensor
核对与原初始 archive 的差异为零；不可用新随机初始化替代。

固定 Qwen3.5-4B、LoRA r16、seed17、tool_example、batch_read_eight、原预算、
奖励、采样及已验收的数值核。24 个尝试槽 G4 共 96 条训练；12 道验证每题两个固定
seed，在尝试槽 0/8/16/24 各 24 条，共 96 条验证。零信号组跳过更新但占用尝试槽。
验证结果不选 checkpoint，主比较固定 0 对 24；保留所有失败和未运行分母。
原学习门槛为最终配对成功差值 > 0 且至少两个家族改善；单 seed、三家族结果仅探索性。
连续十组零信号、fresh-policy 裁剪比例 >5%、资源/安全/未知事务失败即停止。
不更改长度归一化，不自动扩大多 seed、GSPO 或奖励消融。

## 财务与恢复

继续唯一累计 150 元/新增 100 元 financial epoch，不迁移、不重置、不覆盖历史。
本研究附加 60 元硬上限；完整队列所有组均更新的上界为 56.706 元。
运行前必须能覆盖完整剩余队列；最多两次有已确认回执的恢复。
未知采样/优化事务禁止自动重放；pending 预留保留。记录保守占用而非伪造结算账单。

## 验证与结论

源码、队列、配置、数据、历史准入及初始 optimizer 输入均绑定 hash 和源码归档。
确定性脚本/契约运行只证明桥接与状态机，不记为真实模型学习结果。
真实运行后独立重建 G4 奖励、优势、归一化 datum、事务与 fresh-policy 数值。
报告成功率、有效更新比例、裁剪比例、Token、延迟；采样 surprisal 与完整策略熵
分开，完整熵未测。未完成队列不补认学习通过，旧 v1/v2/v3 记录保持原样。

## 实施结果

336 项数据检查通过，队列及资金准入通过。真实运行约 47.12 秒后，保存初始
optimizer checkpoint 的 actor 初始化提交失败（ActorEventSubmitError）。新采样与
更新均 0，初始权重等价性及学习效果未测。只读恢复任务为 ENDED、0 checkpoint，
仍无确认回执；保留 0.100 元 pending，不重放。新增占用 0.160、累计 52.264 元。
报告保留原控制器 pending 状态与完整未运行分母；当前阶段交付停点审计。
