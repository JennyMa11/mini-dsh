### 只读复核与再生成依据

核验JSON由本次只读Python检查生成：输入为来源清单、本轮十份Markdown、固定提交下载的源码bytes、raw独立重取结果与Git改动清单；四门禁字段摘录上表实际命令输出。它不包含自身hash，避免自引用；记录的文档hash包含本报告。来源清单按P0 §1的方法生成，未知项保持未知。重新生成核验记录须重新运行四门禁并记录当次输出，不能复制旧绿灯冒充新运行。

在仓库根目录可用以下命令复核所有文档/本地基线与39份远端源码的bytes（需网络，不安装依赖、不执行第三方源码）；另重新执行上表四命令和`git diff --check`。本轮31个相对链接/锚点已按源文件目录解析并检查目标和Markdown标题，矩阵编号已检查为MV2_01至20且无缺号。

```bash
python3 - <<'PY'
import hashlib
import json
from pathlib import Path
from urllib.request import urlopen

checks = json.loads(Path("docs/results/memory-v2-p0-p1-2026-11-11.checks.json").read_text())
source_path = Path("docs/research/memory-frameworks-2026-11-11.sources.json")
assert hashlib.sha256(source_path.read_bytes()).hexdigest() == checks["source_manifest_sha256"]
sources = json.loads(source_path.read_text())
for path, expected in checks["document_sha256"].items():
    assert hashlib.sha256(Path(path).read_bytes()).hexdigest() == expected, path
for source in sources["local_sources"]:
    assert hashlib.sha256(Path(source["path"]).read_bytes()).hexdigest() == source["sha256"]
count = 0
for project in sources["projects"]:
    for source in project["reviewed_files"]:
        url = f'https://raw.githubusercontent.com/{project["repo"]}/{project["commit"]}/{source["path"]}'
        with urlopen(url, timeout=45) as response:
            assert hashlib.sha256(response.read()).hexdigest() == source["sha256"], url
        count += 1
print(f"Verified {count} pinned source files and recorded document hashes")
PY
```
