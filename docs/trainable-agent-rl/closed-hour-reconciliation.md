# 两个已结算小时的保守费用校准

日期：2026-11-07；适用范围只包括已结束的两批小仓库诊断，不修改旧实验数据或累计上限。

## 外部证据

通过原生Chrome可访问性读取JennyMa工作空间的账单页，登录态检查曾超时，重试后成功加载
近30天全部16条记录。两个相关小时的模型Token账单分别为：

| 显示的本地时段 | 工作空间整小时费用 |
| --- | ---: |
| 2026-11-07 12:00–13:00 | ¥0.22 |
| 2026-11-07 13:00–14:00 | ¥1.47 |

这不是精确的项目/单次RPC归属账单。取**两个小时的整个工作空间模型费用**作为所覆盖
项目调用的更宽上界，不按比例猜测缓存或分摊其他活动。另加每条账单0.01元显示舍入余量，
使用上界1.69+0.02=1.71元。官方已保存前端formatter对模型账期使用本地Date时间，主机
UTC偏移核验为+8；存储记录使用UTC日期，不用于模型小时归属。

只读API认证与owned历史初始训练run查询确认：当前凭据、初始策略及浏览器账单工作空间
均为JennyMa；没有保留凭据字段，没有创建ServiceSession、Sampler或Trainer。

## 操作覆盖证明

- 两批原始完整队列各32条；373+368=741次真实采样。
- 前/中/后费用快照差集恰有741个sample操作，全部estimated，无pending；已有条目没有变化。
- 原始Token逐调用保守估价、操作差集金额和阶段summary均相等：1.982+1.974=3.956元。
- Model Call开始与完成均在UTC04:57:00–05:25:24以内，完整落入上述两个已关闭的本地小时。
  控制器合成终止分别1/9次，单独扣除，没有当成真实模型请求。
- 两份原冻结源码归档共362个文件hash检查通过；控制器在共享预算lease内顺序执行完整队列。
  因此这里建立的是整个cohort操作集合的覆盖，不虚构每个UUID与发票行的一一明细。
- 独立只读拒绝检查覆盖错误工作空间、缺少一个已结算小时、未结算操作、原始调用数不一致，
  四种情况均拒绝，检查过程不改账本。

审计由独立控制面脚本完成，使用提供商UI与只读所有权元数据，未使用模型自报费用。
仅凭工作空间合计或文件hash不足以释放费用；本次还检查了所有权、完整小时、调用集合、
时间包络及冻结控制器。若后续服务商修订账单，需继续保留并处理修订，不把本次视为永久最终发票。
