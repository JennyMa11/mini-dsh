# P5 配对实验：执行契约 v1

实现前冻结，尚未实测。协议为[固定JSON](../benchmarks/memory_v2/p5-protocol.json)，不修改M5历史协议/分母/收益。复用六个已固定任务、现有原生隔离执行器与独立验收、已有六case聚类配对统计；只扩展显式RuntimeOptions注入，不另写Loop/评分器。

Baseline/off、A/v1、B/仅索引、C/索引+主动读取、D/固定整理语料。每题每组3次，共90个机会。四个相邻对照分别是Memory、表示模式、主动工具、整理语料；Baseline→D仅作组合效果，不归因为单个机制。C/D除语料外配置与工具集合相同，A/B除表示模式外相同；所有组的Skills/Verification均关闭，四种基本编码工具固定。上下文full、输入估算8192、输出上限8000字符；主动组只多search/read_memory，全部禁止评测中提议/维护Memory。

固定deepseek-flash、temperature=0、thinking=false、输出1024、模型重试1次。每次12步/24工具/6000 Token/120秒；名义540000 Token，含一次整理及失败/在途超额的全轮上限1080000 Token。达到停止条件不改最后一题额度、不删分母；未知用量立即停止并保持完整消耗未知。只统计Token，不计算金额。该协议仍须与具体种子一起获得新队列批准，尚未发起真实调用。

整理只看到原来三个已批准笔记的正文与来源；不能看到六题答案、隐藏判据、标签或历史反馈。一次整理只选择首个完整environment提议且supersedes精确等于原三个来源的候选，选择规则在结果前固定。其余提议保持未批准。整理输出仍需新的专属环境配置证据和用户对具体修订/hash的批准；历史M5批准不授权新队列。只有脱敏授权材料进入Model，独立判据在Actor移除后才进入另一个容器。

| case_id | 固定检查 | 必须证明 |
| --- | --- | --- |
| P501 | 协议/队列/任务树/源码/判据hash、重复或篡改输入 | 90槽位与3次重复固定；未知/改变/缺失输入拒绝；冻结源可重建，不依赖HEAD或外部动态内容 |
| P502 | 五种实际工具/ModelRequest配置 | off无Store初始化，v1/索引/主动/整理按指定单变量区分；C/D仅语料变动，评测不注册提议/批准工具 |
| P503 | 实际SQLite旧/新种子、来源变化、批准/协议/修订hash不符、synthetic fixture | 精确验证当前授权及独立来源；新整理主张不得继承旧证据；测试身份不能发起真实队列 |
| P504 | 缺授权/凭据/阶段证据、已运行/已预留、改源码、未知预算 | 真实provider与副作用执行目录之前拒绝；明确诊断；不重复队列，不用文件存在冒充进程活跃 |
| P505 | 显式运行外整理与审阅包 | 模型只见原笔记；只产生proposed，原库与原Trace不变；具体正文/修订/来源/input hash可审阅；无自动批准 |
| P506 | 真实容器成功/失败/预算/取消与秘密/写入探针 | 固定1 CPU/1GiB/native、禁网/无挂载；Actor移除后独立验证，所有终态保留产物；Memory库不变；安全失败单列且停止 |
| P507 | 90槽位派生、缺失/零分母/失败消耗/未知用量/超额 | 复用评分器与配对统计，完整分母；至少3次重复；不筛完整子集；保留差值和不确定性/不可评估原因，无脚本收益声明 |
| P508 | 全流程脚本演练及真实实验 | 演练与真实结果区分，Trace/sidecar/实际容器回执/原始响应元数据绑定源码与判据；四门禁；最后按真实证据报告收益或未观察到收益 |

离线组件case外层30秒；隔离集成/全队列演练使用预声明任务预算与顺序执行。真实运行须待凭据和具体审阅包批准，自动续行不代替这两个输入。
