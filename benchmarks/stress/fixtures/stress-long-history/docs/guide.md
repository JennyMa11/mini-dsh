# Module value guide

Every module named `part_NN.py` must expose a single `VALUE` constant.
The constant equals the two-digit module index plus one, so `part_00.py`
holds `VALUE = 1` and `part_15.py` holds `VALUE = 16`.

- `part_00.py`: set `VALUE` to 1 before running the suite.
- `part_01.py`: set `VALUE` to 2 before running the suite.
- `part_02.py`: set `VALUE` to 3 before running the suite.
- `part_03.py`: set `VALUE` to 4 before running the suite.
- `part_04.py`: set `VALUE` to 5 before running the suite.

- `part_15.py`: set `VALUE` to 16 before running the suite.
