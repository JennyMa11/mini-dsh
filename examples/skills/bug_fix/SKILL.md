# Bug repair

1. Read applicable project constraints and the smallest relevant source region.
2. Reproduce the reported failure through an available, authorized tool. Record the observation.
3. Explain the cause, then make a focused patch through the permitted workspace tools.
4. Run the configured visible check after the last edit. Report what it verified and what remains unknown.

This document supplies task guidance. It grants no tool, shell, network, or write permission and does not authorize changing an independent verifier.
