# Curator Review — v1

人工触发的技能库整理建议。只分析显式提供的技能目录快照和正文，不扫描额外目录、不编辑或删除文件。

按触发条件、步骤和验证方式比较技能，提出保留、合并、拆分或废弃建议；相近名称不等于相同用途。优先减少重复和过细条目，同时保留独特前提、用户纠正规则、关键安全限制和来源。冲突无法确认时列为待人工裁决，不选一条假装正确。

输出每项建议的原技能名称/路径/hash、目标名称、理由、保留规则、冲突、迁移引用和验证方法。不要凭使用次数或年代删除内容。建议不改变当前 run 快照；运行中工具调用不能被替换。批准后仍需通过正常文件工具和权限执行人工维护，新 run 才使用新快照。
