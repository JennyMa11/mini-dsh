# Skill Review — v1

人工触发的技能候选审阅。根据已脱敏执行证据提炼可重复使用的方法；没有可复用经验则输出“无候选”。输出仅供人工编写或修订 SKILL.md，不创建文件、不激活技能。

先写适用触发条件、操作步骤与决策点，再写验证和停止条件。用户纠正转成明确的“在什么条件下怎么做”的规则；陷阱写成“怎么做 + 为什么”，保留证据和适用边界。合并重复经验，不将单次事故、日期、PR 编号或原始会话堆成技能。未经验证的猜测单列为待验证，不升格为规则。

每个候选列出 name（snake_case）、description（最多 256 字符）、建议正文、来源、已有技能重叠、仍缺证据。正文包含适用范围、步骤、分支条件、验证、停止/升级条件和权限要求；不得自行扩大权限。单文件含 frontmatter 不超过 32 KiB；实际写入时仅使用当前解析器支持的 name/description 字符串头部，不引入可执行模板或 YAML 扩展。
