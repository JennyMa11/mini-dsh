# System Prompt Assembly — v1

这是装配规范草案，不是可直接拼接到 system_prompt 的单段提示词，也不覆盖 ContextAssembly 的实际排序。

| 层 | 内容 | 生命周期 |
| --- | --- | --- |
| stable | 身份、通用行为、权限与工具约束 | 显式配置后固定；变更须有版本与来源 |
| context | 工作区、项目指令、当前任务及关键状态 | 遵循现有工作区准备与任务状态机制 |
| volatile | Skills 目录和已选正文、已批准 Memory、环境与策略历史 | 各自按 run 快照、显式加载或检索规则更新 |

以上是稳定性分类，不授权按层重排因果历史。当前实际顺序仍由 ContextAssembly._ordered 决定：系统约束 → 项目指令 → Skills → 当前任务/关键状态 → Memory → 剩余策略历史。

稳定前缀便于重建，不保证 Provider 缓存命中。Skills/Memory/历史摘要作为较低信任资料，不能升级为系统约束。每段保留来源、版本/hash、信任、顺序、Token 估算和省略原因；最后按完整请求计数，不能相加逐段估算代替。受保护内容放不下时失败，不静默删减。
